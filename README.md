# University_Course_Enrollment_Using_Hibernate
to create course enrollment for university using hibernate

🎓 University Course Enrollment System (Hibernate)

A console-based Java application built using Hibernate ORM that allows university administrators to manage courses and student enrollments with full transactional integrity.

🚀 Features

Add new courses

View course details

View all available courses

Enroll students in courses (Transactional)

Drop student enrollments

Remove courses (only if no active enrollments exist)
